# Xcode-27-Skills

A personal archive of the built-in coding skills exported from Xcode 27.1 beta.

## Included skills

The archive contains the complete Xcode 27.1 beta skill set: accessibility, App Intents, app resizability, document-based SwiftUI apps, device interaction, test modernization, translation, UIKit modernization, SwiftUI guidance, C bounds safety, and Xcode security settings.

## Refreshing the archive

Use an Xcode 27.1 beta installation to regenerate the skills, then replace this directory with the export output:

```sh
xcrun agent skills export --replace-existing ./xcode-skills
```

This repository intentionally tracks the exported Xcode skill contents rather than version-specific wrapper documentation.
